# Inventory Manager

Inventory Manager is a small command-line application for keeping track of
items, categories, and quantities. Changes are saved to a plain-text file.

## What you can do

- View all items in a numbered list.
- Add an item with a name, category, and quantity.
- Change the quantity of an existing item.
- Remove an item.
- Search item names without matching capitalization exactly.
- View item, quantity, category, and low-stock totals.
