# AI Assistance and Verification

ChatGPT assisted with preparing this Homework 4 package. It selected Ruff
and MkDocs from the approved tool list, read official documentation, copied
the supplied HW1 checkpoint into a separate HW4 project, configured the
tools, and applied Ruff's suggested fix and formatting. It also drafted the
MkDocs pages, README, TOOLS.md reflection, evidence notes, and upload guide.

The recorded commands were actually run in the assistant workspace. The
tool logs and screenshots are evidence of those runs, not a claim that the
student independently performed those commands. The student should review
the work, understand the changes, and revise the personal reflection before
submission according to the course's AI-use rules.

Behavior verification compared the preserved starting source with the final
source using temporary copies of data. It checked save/load behavior for
empty, single-record, multiple-record, and UTF-8 data; view, summary, search,
add, update, and remove workflows; and ordinary invalid inputs.

The supplied `TESTING.md` is the historical HW1 manual testing record.
The 47-test HW2 screenshot was not used as a new execution result because
the corresponding test file was not provided. This package does not claim
full test coverage, absence of all bugs, a measured performance gain, or a
guaranteed grade.

The baseline source is retained as
`evidence/baseline_inventory_manager.py.txt`, and its original SHA-256 digest
is recorded in `evidence/baseline_sha256.json`.

At preparation time, the package has not been pushed to the student's GitHub
account or submitted to Blackboard. Those steps must be completed separately.
